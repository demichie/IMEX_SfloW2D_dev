# Canonical Etna terrain

`Etna2014_crop.zip` is the canonical committed Etna DEM archive, shared by
`EXAMPLE_ETNA`, `EXAMPLE_ENSEMBLE_ETNA`, and `EXAMPLE_ETNA_LAVA`.

From `EXAMPLE_ETNA`:

```bash
unzip DEM/Etna2014_crop.zip -d DEM
```

The avalanche preprocessing creates additional rasters in this directory,
including `new_dem.asc` and `init_volume.asc`.
