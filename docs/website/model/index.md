# Physical and numerical model

IMEX_SfloW2D is a depth-averaged solver for volcanic and related geophysical flows. The code includes multiple physical closures and rheological formulations, reconstructive finite-volume spatial operators and implicit-explicit time integration.

The precise governing equations and options depend on the selected physical setup. The individual [examples](../examples/index.md) document the tested configurations; the generated [Doxygen reference](https://demichie.github.io/IMEX_SfloW2D_dev/doxygen/) describes source-code modules and procedures.

Scientific acceptance evidence is maintained in the repository under [`docs/acceptance`](https://github.com/demichie/IMEX_SfloW2D_dev/tree/master/docs/acceptance).
