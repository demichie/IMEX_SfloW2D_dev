# References and citation

If you use IMEX-SfloW2D in research, please cite the **software version
you used** and the scientific publications relevant to your chosen
physical models and numerical methods.

## Cite IMEX-SfloW2D

**de' Michieli Vitturi, Mattia.** *IMEX-SfloW2D.*
Open-source scientific software, Istituto Nazionale di Geofisica e
Vulcanologia. Repository:
[github.com/demichie/IMEX_SfloW2D_dev](https://github.com/demichie/IMEX_SfloW2D_dev).

In a publication or reproducibility record, include the release tag
or exact Git commit, the date of access when appropriate, and the
simulation configuration. The repository supplies machine-readable
citation metadata in
[`CITATION.cff`](https://github.com/demichie/IMEX_SfloW2D_dev/blob/master/CITATION.cff);
GitHub's **Cite this repository** feature can export the software
reference.

For an immutable software version, consult
[GitHub Releases](https://github.com/demichie/IMEX_SfloW2D_dev/releases).
If the version used has no published release, report its full commit SHA.

## Cite the scientific models used in your study

A software citation does not replace citations for the governing
equations, rheological model, material properties, calibration datasets
or numerical methods used in a particular simulation.

Choose the relevant scientific publications for the laws and
assumptions actually enabled in your input file. Do not attribute
the validation of one example or rheology to all other configurations.

For details of which model terms were used, see
[Physical and numerical model](../model/index.md).
