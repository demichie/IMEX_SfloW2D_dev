# IMEX-SfloW2D

**A depth-averaged, finite-volume model for volcanic and other geophysical flows.**

IMEX-SfloW2D integrates high-resolution spatial reconstruction with implicit-explicit time integration and cell-local constitutive laws. The same solver supports **one layer** or **two interacting layers**, selected through `N_LAYERS` in the input file.

!!! warning "Scientific scope of the two-layer model"
    The two-layer formulation is integrated into the normal solver, but its coupled gravitational eigenvalues can become complex for some densities or relative velocities. A completed run does not certify hyperbolicity or physical calibration. See the [two-layer limits](model/two-layer.md).
