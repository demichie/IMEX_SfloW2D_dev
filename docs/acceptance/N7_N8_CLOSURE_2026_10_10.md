## Meaning of closure status

`satisfied` means the named original contract has direct passing evidence within
its defined fixtures. It does not mean every physical model has been exhaustively
tested. `partial` means specific original assertions remain; `missing` means the
particular required case lacks automated production evidence. A decision requires
an explicit acceptance interpretation, not an automatic code change.

Coverage boundaries and outstanding requirements are different. A note saying
that a liquid fixture does not cover every rheology, boundary or future MPI
configuration does not itself create another mandatory N7/N8 test. Conversely,
the explicit refinement and repeated-update tests in section 15.3 cannot be
removed merely because the global volume identity already passes.

N9 sign-off remains separate. Passing an execution script cannot automatically
approve N7, N8 or the scientific baseline.
